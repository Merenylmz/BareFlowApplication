# BareFlowApplication

## 🎯 Projenin Amacı
BareFlowApplication, React Native ve Expo altyapısı kullanılarak geliştirilmiş, "bare" (doğal/özelleştirilmiş) çalışma ortamına sahip bir mobil uygulamadır. Proje, hem iOS hem de Android platformlarında yerel (native) modülleri destekleyecek şekilde yapılandırılmıştır.

Uygulama temel olarak konum servislerini (`expo-location`) kullanabilen, yüksek performanslı ve özelleştirilebilir bir mobil altyapı sunar. Geliştiricilerin native kütüphanelere kolayca erişebilmesi için `expo run` komutlarıyla yerel derleme (build) süreçlerini destekler.

## 🛠️ Kullanılan Teknolojiler
*   **Framework:** React Native, Expo
*   **Dil:** JavaScript
*   **Versiyon Kontrol:** Git
*   **Konum Servisleri:** expo-location
*   **Platform Desteği:** iOS, Android, Web

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edin:

1. **Repoyu Klonlayın:**
   ```bash
   git clone <repo-url>
   cd BareFlowApplication
   ```

2. **Bağımlılıkları Kurun:**
   ```bash
   npm install
   ```

3. **Uygulamayı Çalıştırın:**
   * **Geliştirme Modu:**
     ```bash

     ```
   * **Android:**
     ```bash
     npm run android
     ```
   * **iOS:**
     ```bash
     npm run ios
     ```
   * **Web:**
     ```bash
     npm run web
     ```

# BareFlowApplication

## 🎯 Project Purpose
BareFlowApplication is a mobile application developed using React Native and the Expo framework with a "bare" workflow configuration. The project is structured to support native modules across both iOS and Android platforms.

The application is built to handle location services via `expo-location` and provides a high-performance, customizable mobile infrastructure. By utilizing the `expo run` command, it allows developers to build and manage native code easily, making it suitable for projects requiring deeper native integration.

## 🛠️ Technologies Used
*   **Framework:** React Native, Expo
*   **Language:** JavaScript
*   **Version Control:** Git
*   **Location Services:** expo-location
*   **Platform Support:** iOS, Android, Web

## 🚀 Installation and Usage

Follow these steps to set up the project in your local environment:

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd BareFlowApplication
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the application:**
   * **Development Mode:**
     ```bash
     npm start
     ```
   * **Android:**
     ```bash
     npm run android
     ```
   * **iOS:**
     ```bash
     npm run ios
     ```
   * **Web:**
     ```bash
     npm run web
     ```
